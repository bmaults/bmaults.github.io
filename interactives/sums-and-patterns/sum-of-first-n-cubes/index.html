The Sum of the First n Cubes: 1³ + 2³ + ... + n³ = (1 + 2 + ... + n)²

The side of this square is 1 + 2 + ⋯ + n, and it is built from L-shaped layers. The layer of width k can be straightened into a bar. Use the sliders to see how.

Questions to think about

  1. Can you prove this identity with induction?
  2. The bar for layer k is k wide and k² tall. Why does the L-shape have exactly that length when straightened?
