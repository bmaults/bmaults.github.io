The Mean Value Theorem for Integrals: The Average Value of a Function

The area under a curve can be turned into a rectangle with the same area. The height of that rectangle is the average value of the function.

Questions to think about

  1. Is there always a point c where the function equals its average value? What would go wrong if the function jumped?
  2. What happens to the balancing height if you move the right end b?
